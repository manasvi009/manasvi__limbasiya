================================================================================
  DEPLOY YOUR FULL-STACK PORTFOLIO TO VERCEL IN 15 MINUTES
================================================================================

Your application is ready! Follow these steps:

┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 1: SETUP MONGODB (3 minutes)                                          │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ 1. Go to: https://www.mongodb.com/cloud/atlas                             │
│ 2. Create free M0 cluster                                                  │
│ 3. Create database user (Save password!)                                   │
│ 4. Click "Connect" → "Drivers" → "Node.js"                                │
│ 5. Copy connection string                                                  │
│ 6. Go to "Network Access" → Allow all IPs (0.0.0.0/0)                    │
│                                                                             │
│ Your string will look like:                                                │
│ mongodb+srv://user:pass@cluster0.xyz.mongodb.net/portfolio?retryWrites... │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 2: GENERATE SECURITY KEY (1 minute)                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ Run in terminal:                                                            │
│ $ openssl rand -base64 32                                                  │
│                                                                             │
│ Copy the output (looks like: aB1cD2eF3gH4iJ5kL6mN7oP8qR9sT0uVwXyZ+/=)   │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 3: DEPLOY ON VERCEL (5 minutes)                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ 1. Go to: https://vercel.com                                              │
│ 2. Sign in (or create free account)                                        │
│ 3. Click "Add New" → "Project"                                            │
│ 4. Click "Import Git Repository"                                          │
│ 5. Select your GitHub repository                                          │
│ 6. Click "Import"                                                         │
│                                                                             │
│ 7. ADD ENVIRONMENT VARIABLES:                                             │
│                                                                             │
│    ┌──────────────────────────────────────────────────────────────────┐   │
│    │ MONGODB_URI                                                      │   │
│    │ (your connection string from Step 1)                            │   │
│    └──────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│    ┌──────────────────────────────────────────────────────────────────┐   │
│    │ NEXTAUTH_SECRET                                                  │   │
│    │ (your generated key from Step 2)                                │   │
│    └──────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│    ┌──────────────────────────────────────────────────────────────────┐   │
│    │ NEXTAUTH_URL                                                     │   │
│    │ https://YOUR_PROJECT_NAME.vercel.app                            │   │
│    └──────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│    ┌──────────────────────────────────────────────────────────────────┐   │
│    │ NEXT_PUBLIC_SITE_URL                                             │   │
│    │ https://YOUR_PROJECT_NAME.vercel.app                            │   │
│    └──────────────────────────────────────────────────────────────────┘   │
│                                                                             │
│ 8. Click "Deploy"                                                         │
│ 9. Wait 2-5 minutes...                                                    │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 4: TEST YOUR SITE (3 minutes)                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ ✓ Click "Visit" to open your live site                                    │
│ ✓ Homepage loads                                                           │
│ ✓ Can navigate to blog                                                     │
│ ✓ Can view blog posts                                                      │
│ ✓ Can view projects                                                        │
│ ✓ Can sign up for account                                                  │
│ ✓ Can submit newsletter                                                    │
│ ✓ Can submit contact form                                                  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ STEP 5: CUSTOM DOMAIN (Optional, 2 minutes)                                │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│ If you have your own domain:                                               │
│                                                                             │
│ 1. In Vercel project → Settings → Domains                                 │
│ 2. Enter your domain name                                                  │
│ 3. Update DNS at your registrar (follow Vercel's instructions)            │
│ 4. Update NEXTAUTH_URL and NEXT_PUBLIC_SITE_URL to your domain           │
│ 5. Redeploy                                                                │
│                                                                             │

================================================================================
  TROUBLESHOOTING
================================================================================

Build Error?
  → Check Vercel deployment logs
  → Verify all 4 environment variables are added
  → Check MongoDB connection string

Can't Login?
  → Clear browser cookies
  → Check NEXTAUTH_URL matches your domain
  → Verify NEXTAUTH_SECRET was added

Database Error?
  → MongoDB cluster must be running
  → IP whitelist must include your address
  → Connection string must be correct
