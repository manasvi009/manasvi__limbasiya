QUICK 30-MINUTE DEPLOYMENT PROCESS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. MongoDB Setup (10 min)
   → mongodb.com/cloud/atlas → Create FREE cluster → Get connection string

2. Security Key (1 min)
   → generate-secret.vercel.app/32 → Copy secret

3. Push Code (5 min)
   → v0 Settings → Git → Push code to GitHub
   → OR: git push origin full-stack-deployment

4. Add Variables (5 min)
   → vercel.com/dashboard → Your Project → Settings → Environment Variables
   → Add 4 variables (see below)

5. Deploy (2 min)
   → Vercel deploys automatically
   → Wait for green checkmark

6. Visit Your Site (Instant!)
   → https://manasvi-limbasiya.vercel.app ✅


4 ENVIRONMENT VARIABLES YOU NEED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

In Vercel, add these 4 environment variables:

  1. MONGODB_URI
     Value: Your MongoDB connection string

  2. NEXTAUTH_SECRET
     Value: Your generated secret from step 2

  3. NEXTAUTH_URL
     Value: https://manasvi-limbasiya.vercel.app

  4. NEXT_PUBLIC_SITE_URL
     Value: https://manasvi-limbasiya.vercel.app

Q: How long does deployment take?
A: About 30 minutes total for all steps

Q: What if deployment fails?

Q: Can I use a custom domain?

Q: What if I make changes later?
