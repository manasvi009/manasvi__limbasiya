  QUICK DEPLOYMENT (15 MINUTES)
================================================================================

1. Setup MongoDB (3 minutes):
   → Go to: https://www.mongodb.com/cloud/atlas
   → Create free M0 cluster
   → Get connection string
   → Whitelist all IPs (0.0.0.0/0)

2. Generate Security Key (1 minute):
   → Run: openssl rand -base64 32
   → Copy the output

3. Deploy to Vercel (5 minutes):
   → Go to: https://vercel.com
   → Import GitHub repository
   → Add 4 environment variables:
     - MONGODB_URI
     - NEXTAUTH_SECRET
     - NEXTAUTH_URL
     - NEXT_PUBLIC_SITE_URL
   → Click Deploy
   → Wait 2-5 minutes

4. Test Your Site (3 minutes):
   → Visit your live URL
   → Test homepage, blog, projects, auth, forms
   → Done!

================================================================================
  ENVIRONMENT VARIABLES YOU'LL NEED
================================================================================

You need exactly 4 environment variables to deploy:

┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. MONGODB_URI                                                              │
│    Example: mongodb+srv://user:pass@cluster0.xyz.mongodb.net/portfolio    │
│    Where:   Get from MongoDB Atlas "Connect" section                       │
│                                                                             │
│ 2. NEXTAUTH_SECRET                                                          │
│    Example: aB1cD2eF3gH4iJ5kL6mN7oP8qR9sT0uVwXyZ+/=abc=                  │
│    How:     Run: openssl rand -base64 32                                  │
│                                                                             │
│ 3. NEXTAUTH_URL                                                             │
│    Example: https://yoursite.vercel.app                                   │
│    Set to:  Your Vercel URL or custom domain                              │
│                                                                             │
│ 4. NEXT_PUBLIC_SITE_URL                                                     │
│    Example: https://yoursite.vercel.app                                   │
│    Set to:  Same as NEXTAUTH_URL                                          │
└─────────────────────────────────────────────────────────────────────────────┘

Add these in Vercel Project Settings → Environment Variables

================================================================================
  TROUBLESHOOTING
================================================================================

"MONGODB_URI is not set"
  → Add MONGODB_URI to Vercel environment variables
  → Verify variable name is exact
  → Redeploy application

"Can't login / Authentication not working"
  → Check NEXTAUTH_SECRET is added
  → Verify NEXTAUTH_URL matches your domain
  → Clear browser cookies
  → Check browser console (F12) for errors

"Database connection timeout"
  → Verify MongoDB cluster is running
  → Check IP whitelist includes your address
  → Verify connection string is correct
  → MongoDB Atlas might need time to initialize

"Build fails"
  → Check Vercel deployment logs
  → Verify all environment variables are set
  → Run locally: npm run build
  → Check for TypeScript errors: npx tsc --noEmit

Cannot find other issues?
  → See detailed troubleshooting in VERCEL_DEPLOYMENT.md
  → Check PRE_DEPLOYMENT_CHECKLIST.md for testing
