Issue: "Environment variables not working"
Fix:   Redeploy after adding variables
       Go to Deployments → Click latest → Redeploy

Issue: "MongoDB connection failed"  
Fix:   Double-check connection string
       Replace <password> with actual DB password
       Test connection in MongoDB Atlas

Issue: "Site not loading"
Fix:   Wait 1-2 minutes for cold start
       Refresh browser (Ctrl+Shift+R)
       Check browser console (F12)

Issue: "Authentication errors"
Fix:   Verify NEXTAUTH_URL is exactly: https://manasvi-limbasiya.vercel.app
       Check NEXTAUTH_SECRET is added
       Variables are case-sensitive!
