## Quick Reference: Your 4 Variables

You'll need to collect these 4 values and add them to Vercel:

| Variable | Source | Looks Like |
|----------|--------|-----------|
| `MONGODB_URI` | MongoDB Atlas | `mongodb+srv://user:pass@cluster.mongodb.net/...` |
| `NEXTAUTH_SECRET` | Terminal command | `aB1cD2eF3gH4iJ5kL6mN7oP8qR9sT0uVwXyZ+/=` |
| `NEXTAUTH_URL` | Vercel project name | `https://yourproject.vercel.app` |
| `NEXT_PUBLIC_SITE_URL` | Same as above | `https://yourproject.vercel.app` |

Instructions for each are in your chosen guide.

## Common Questions

### "How much does this cost?"
**Answer**: Free! Vercel and MongoDB both have free tiers.

### "Will my code be safe?"
**Answer**: Yes! All sensitive data stays in environment variables, never in code.

### "How do I add my own domain?"
**Answer**: In Vercel Project Settings → Domains. You can do this anytime.

### "Can I do this on my phone?"
**Answer**: Kind of. Better to use a computer for copy-pasting connection strings.

### "What if something breaks?"
