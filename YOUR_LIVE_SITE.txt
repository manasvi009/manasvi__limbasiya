TROUBLESHOOTING

Problem: Deployment shows red X
Solution: Check logs → Deployments → Click failed → View Logs
          Most common: Missing environment variables

Problem: Site doesn't load
Solution: Wait 1-2 minutes for cold start
          Refresh browser (Ctrl+Shift+R)
          Check browser console (F12)

Problem: MongoDB not connecting
Solution: Verify connection string in environment variables
          Check MongoDB cluster is running
          Verify username/password in connection string

Problem: Authentication not working
Solution: Check NEXTAUTH_SECRET is set
          Verify NEXTAUTH_URL is exactly: https://manasvi-limbasiya.vercel.app
          Variables are case-sensitive!
